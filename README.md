# Contacts App

A native iOS contacts application built as an earlier UIKit project.

The project was created to practice building list-based interfaces, handling navigation, managing contact data, and structuring a small iOS application.

> **Project Note**
>
> This is an older learning project and is preserved as part of my iOS development journey.
>
> It reflects the UIKit development practices I was using at that stage and is not intended to represent my current architecture or engineering approach.

## Features

- Display contacts in a list
- Contact detail screens
- Navigation between screens
- Reusable table view cells
- Basic contact management flows
- UIKit-based interface
- Unit test target
- UI test target

## Tech Stack

- Swift
- UIKit
- UITableView
- Xcode
- XCTest

## Running the Project

Clone the repository:

```bash
git clone https://github.com/himanshu240601/contacts-app.git
cd contacts-app
```

Open the project in Xcode:

```bash
open ContactsApp.xcodeproj
```

Select an iOS simulator or physical device and run the project.
